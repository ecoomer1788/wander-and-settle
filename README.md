# Wander & Settle

A responsive, accessible homepage for an Ivy Tech web development course project. The site helps people explore moving abroad.

## Files
- `index.html`: Semantic homepage content
- `style.css`: Responsive desktop and mobile styling
- `script.js`: Accessible mobile navigation toggle

## Accessibility
- Semantic header, nav, main, sections, and footer
- Skip-to-content link and visible keyboard focus styles
- Descriptive navigation links and `aria-current`
- Accessible mobile menu with `aria-expanded` and `aria-controls`
- Text descriptions for destination illustrations
- Responsive layout and reduced-motion support

## Future development
Moving checklist, destination comparison, and destination-fit quiz are placeholders for future modules.

## Publish on GitHub Pages
1. Create a public repository named `wander-and-settle`.
2. Upload the files in this folder to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then **main** and **/(root)**, and save.
5. Wait for GitHub to provide the published URL.
6. Submit both the repository URL and the live GitHub Pages URL to Canvas.

The contact section is intentionally marked as coming soon; no personal email address is included.
