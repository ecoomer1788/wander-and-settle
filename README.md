# Wander & Settle — Website Update

Five-page responsive student website for SDEV153.

## Publishing to GitHub Pages
1. Open your existing `wander-and-settle` repository on GitHub.
2. Back up existing files first.
3. Upload **all** files and the `images` folder contents from this package to the repository root. Replace `index.html` and other matching files when prompted.
4. Commit the changes and wait for GitHub Pages to publish.
5. Visit your existing Pages URL and test each navigation link, quiz, checklist, and mobile layout.

The quiz and checklist run in the browser; no personal data is submitted. Illustrations are original SVG files.

## Audit reminders
Verify HTML and CSS validation, keyboard-only navigation, zoom, contrast, and mobile behavior in your own browser before marking those items Yes. The website has 5 HTML pages, 3 destination images, a comparison table, an ordered list, external official links, a validated quiz form, and one external CSS file.
